Today, we're shipping two new releases:

* xUnit.net Core Framework v3 `4.0.1` ([release notes](/releases/v3/4.0.1))
* **xUnit.net Analyzers `2.1.0`**

It's been 4 weeks since the release of [`2.0.0`](/releases/analyzers/2.0.0).

As always, we'd like to thank all the users who contributed to the success of xUnit.net through usage, feedback, and code. 🎉

## Release Notes

These release notes are a comprehensive list of changes from `2.0.0` to `2.1.0`.

### Usage Analyzers

* We have updated [xUnit1005](/xunit.analyzers/rules/xUnit1005) to add support for `CulturedFactAttribute` and `CulturedTheoryAttribute`.

* We have updated [xUnit1037](/xunit.analyzers/rules/xUnit1037), [xUnit1038](/xunit.analyzers/rules/xUnit1038), [xUnit1039](/xunit.analyzers/rules/xUnit1039), and [xUnit1040](/xunit.analyzers/rules/xUnit1040) to support tuples (in addition to `TheoryData<>` and `TheoryDataRow<>`). [xunit/xunit#3617](https://github.com/xunit/xunit/issues/3617){: .issue-link }

* We have updated [xUnit1041](/xunit.analyzers/rules/xUnit1041) to add support for `AssemblyFixtureAttribute<T>`. [xunit/xunit#3619](https://github.com/xunit/xunit/issues/3619){: .issue-link }

* We have updated [xUnit1044](/xunit.analyzers/rules/xUnit1044) and [xUnit1054](/xunit.analyzers/rules/xUnit1054) to add support for `ClassDataAttribute<T>`. [xunit/xunit#3622](https://github.com/xunit/xunit/issues/3622){: .issue-link }

* We have updated the message for [xUnit1048](/xunit.analyzers/rules/xUnit1048), which still currently reference to the release of v3 as something happening in the future.

### Extensibility Analyzers

* We have updated [xUnit3005](/xunit.analyzers/rules/xUnit3005) to add support for:

  * `CollectionBehaviorAttribute<T>`
  * `RegisterConsoleResultWriterAttribute<T>`
  * `RegisterMicrosoftTestingPlatformResultWriterAttribute<T>`
  * `RegisterResultWriterAttribute<T>`
  * `RegisterRunnerReportAttribute<T>`
  * `TestCaseOrdererAttribute<T>`
  * `TestClassOrdererAttribute<T>`
  * `TestCollectionOrdererAttribute<T>`
  * `TestMethodOrdererAttribute<T>`
  * `TestPipelineStartupAttribute<T>`

  [xunit/xunit#3622](https://github.com/xunit/xunit/issues/3622){: .issue-link }

* **BUG:** We have fixed an issue with [xUnit3005](/xunit.analyzers/rules/xUnit3005) which was causing false positives for legal assembly fixture parameters (namely, `IMessageSink diagnosticMessageSink`, `ITestContextAccessor accessor`, and `ITestOutputHelper outputHelper`). [xunit/xunit#3618](https://github.com/xunit/xunit/issues/3618){: .issue-link }
