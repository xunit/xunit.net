Today, we're shipping two new releases:

* xUnit.net Core Framework v3 `4.0.3` ([release notes](/releases/v3/4.0.3))
* **xUnit.net Analyzers `2.3.0`**

It's been 4 weeks since the release of [`2.2.0`](/releases/analyzers/2.2.0).

As always, we'd like to thank all the users who contributed to the success of xUnit.net through usage, feedback, and code. 🎉

## Release Notes

These release notes are a comprehensive list of changes from `2.2.0` to `2.3.0`.

### Usage Analyzers

* We have added [xUnit1073](/xunit.analyzers/rules/xUnit1073) to detect unused collection definitions. _Note: This is a post-compile analyzer, so it may not show up in real time (or highlighted in the source code). It will be reported when the test project is compiled._ [xunit/xunit#1277](https://github.com/xunit/xunit/issues/1277){: .issue-link }

* **BUG:** We have fixed an issue with [xUnit1024](/xunit.analyzers/rules/xUnit1024) where it did not properly differentiate between interface abstract and default methods. We have also updated the message slightly to talk about 'types' rather than 'test classes' so that it's clearer that the overload might be coming from an interface default method. [xunit/xunit#3655](https://github.com/xunit/xunit/issues/3655){: .issue-link }

* **BUG:** We have fixed an issue with [xUnit1045](/xunit.analyzers/rules/xUnit1045) where it was not properly reading `DisableDiscoveryEnumeration` on `[CulturedTheory]`. [xunit/xunit#3650](https://github.com/xunit/xunit/issues/3650){: .issue-link }

### Assertion Analyzers

* **BUG:** We have fixed an issue with [xUnit2023](/xunit.analyzers/rules/xUnit2023) where the fixer was incorrectly deleting some inspectors. Some previously broken expressions were correctly fixed, and others which could not be fixed automatically no longer offer the fix. [xunit/xunit#3659](https://github.com/xunit/xunit/issues/3659){: .issue-link }

* **BUG:** We have fixed an issue with [xUnit2024](/xunit.analyzers/rules/xUnit2024) which would suggest using `Assert.Not` or `Assert.NotNull` with values which aren't compatible with those methods (namely, `void*` and `delegate*`). [xunit/xunit#3663](https://github.com/xunit/xunit/issues/3663){: .issue-link }
